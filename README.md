# TBM-Torque-GRU-RMDD
## Code and Data Availability
The code and data supporting this study will be made publicly available upon final acceptance of the manuscript.
To facilitate the distribution and download of the large-scale dataset, the dataset will be hosted on cloud storage. Access links and download instructions will be provided in this repository upon release.


The Yinsong (YS) dataset is described in the following publication:
Li, J.-B., Chen, Z.-Y., Li, X., et al. (2023).
Feedback on a shared big dataset for intelligent TBM Part I:
Feature extraction and machine learning methods.
Underground Space, 11, 1–25.
[Article](https://doi.org/10.1016/j.undsp.2023.01.001)
The original GitHub repository referenced in this publication
provides related data and documentation:
[YS-IWHR repository](https://github.com/ChenZuyuIWHR/YS-IWHR)
